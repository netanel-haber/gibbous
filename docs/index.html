gibbous 🌔

A Chrome extension for hiding the useless parts of GitHub UI.

download .zip source
1.

Dashboard

Strips clutter, expands Top repositories, links forks upstream.

2.

Sidebar

Prunes navigation, fills Top repositories, dedupes your forks.

3.

Repository navigation

Hides unused tabs and links upstream repositories to your fork.

4.

Pull request shortcuts

Links your open and closed pull requests beside the PR tab.

5.

Files and folders

Hides top-level entries on hover. Restore them from the eye menu.

6.

Quote navigation

Links quoted comments both ways and reveals unloaded ones.

7.

Mermaid

Opens Mermaid diagrams in a lightbox. Scroll to zoom, drag to pan.
