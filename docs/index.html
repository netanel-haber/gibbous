gibbous 🌔

A Chrome extension for hiding the useless parts of GitHub UI.

download .zip source
1.

Dashboard

Removes the Copilot prompt, changelog, and Home / Feed navigation.

2.

Repository navigation

Hides unused tabs and links upstream repositories to your fork.

3.

Pull request shortcuts

Adds direct links to your open and closed pull requests beside the repository tab.

4.

Files and folders

Hides top-level entries on hover. Restore them from the eyes menu. The list persists per fork network.

5.

Quote navigation

Links quoted PR comments both ways, previews matches, and reveals unloaded comments.
