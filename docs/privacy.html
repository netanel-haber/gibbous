Gibbous privacy policy

Last updated: October 27, 2026

Gibbous is a browser extension that changes how GitHub looks and adds controls to it. It has no server of its own and no analytics. Nothing it reads or stores is sent to its developer or to anyone else.

What Gibbous reads

On github.com, Gibbous reads the pages you open, so it can rearrange them. To fill in what a page leaves out, it asks GitHub itself, from your browser and as you, with your GitHub session:

  • GitHub pages: a repository's tags, your fork of a repository, the comments a pull request folds away;
  • GitHub's public search API (api.github.com): your open pull requests on a repository;
  • a pull request's diff (github.com/…/pull/….diff, which GitHub serves from patch-diff.githubusercontent.com): to count its changed lines with whitespace ignored.

It also runs in the frame GitHub draws Mermaid diagrams in (viewscreen.githubusercontent.com), to zoom and pan them, and on this site, to show it in your GitHub theme.

What Gibbous stores

Only in your browser, in the extension's local storage (with a copy in github.com's local storage, so pages appear right away):

  • whether Gibbous is on;
  • the files and repositories you chose to hide, and the diff hunks you marked as viewed;
  • your GitHub theme;
  • facts about repositories it has looked up (such as whether you have a fork), and comments it matched to quoted replies, for a short time, so the same page does not ask GitHub again.

Removing the extension deletes its own storage; the copy on github.com stays until you clear github.com's site data. Nothing is synced or shared.

What Gibbous does not do

It does not collect, sell or share data, show ads, track you across sites, or load code from anywhere: everything it runs ships inside the extension.
