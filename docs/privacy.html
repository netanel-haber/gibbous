Gibbous privacy policy

Last updated: October 27, 2026

Gibbous changes how GitHub's pages look. It has no server and no analytics, and it sends nothing to me or to anyone else.

What it reads

On github.com it reads the page you're on, so it can change it. It also requests a few things from GitHub, with your login, the way the page itself would:

  • other GitHub pages: a repo's tags, whether you have a fork, comments GitHub collapsed;
  • GitHub's search API (api.github.com), to find your open pull requests in a repo;
  • a pull request's .diff, which GitHub serves from patch-diff.githubusercontent.com, to count changed lines without whitespace.

It also runs in the frame GitHub draws Mermaid diagrams in (viewscreen.githubusercontent.com), to zoom and pan them.

What it stores

Settings and a short-term cache, in your browser only: in the extension's storage, with a copy in github.com's local storage so pages load right.

  • whether it's on;
  • the files and repos you hid, and the diff hunks you marked as viewed;
  • recent lookups, like whether you have a fork, and quote matches.

Uninstalling deletes the extension's storage. The copy on github.com stays until you clear github.com's site data.

What it doesn't do

No ads, no tracking, no selling or sharing data, and no code loaded from anywhere.
